# Innovation Club // DPS Newtown

The website for DPS Newtown's Innovation Club: a public blog, a member
directory, and a project portal where members log progress on what they're
building.

## What's on the site

- **Blog** — dated posts organized into domains (categories), with comments,
  likes, an archive view, and per-post "repost" tools (downloadable
  Instagram-story image, embeddable card, copy link).
- **Member directory** — every member's profile, role, domain, and the
  projects/posts they're linked to. Each profile shows a live attendance
  figure pulled from an external spreadsheet.
- **Project portal** — a members-only area (`/portal`) where logged-in
  members create and update projects, invite collaborators with equal edit
  rights, and see admin announcements.
- **Admin console** (`/admin`) — a PIN-gated control panel for managing
  posts, domains, the gallery, members, and announcements.
- **Question of the Day** — a homepage widget with a fresh daily question,
  generated by a scheduled AI job, open to members and Google-signed-in
  visitors alike.
- **Embeds** — `/embed` (the whole feed) and `/embed/post/:slug` (a single
  post) render as minimal iframe-friendly cards for embedding elsewhere.

## Stack

- **Frontend** — React 18 + Vite, React Router, TanStack Query, Tailwind CSS.
- **Backend** — [Supabase](https://supabase.com): Postgres, Row Level
  Security, Storage, and a scheduled Edge Function.
- **Hosting** — [Vercel](https://vercel.com), deployed as a static SPA.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — production build to `dist/`
- `npm run preview` — preview the production build locally
- `npm run lint` / `npm run lint:fix` — ESLint
- `npm run typecheck` — `tsc` against `jsconfig.json`
